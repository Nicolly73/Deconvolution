Desconvolução Supervisionada:
Norma $L_2$ e Correntropia

Relação entre a formulação teórica, o desenvolvimento das derivadas parciais e a implementação em MATLAB com wavelet conhecida.

Objetivos da Aula

  • Modelar o problema direto através da convolução discreta e predição do traço sísmico.
  • Deduzir a função custo e as derivadas parciais usando a Norma $L_2$ (Erro Quadrático Médio).
  • Implementar o algoritmo de Gradiente Descendente para minimizar o erro $L_2$.
  • Deduzir a função custo e as derivadas parciais baseadas em Correntropia (núcleo Gaussiano).
  • Implementar o algoritmo de Gradiente Ascendente para maximizar a correntropia.

Arquitetura do Código Desenvolvido

  • convolution.m e prediction.m — Modelação direta do sinal.
  • cost_L2.m, partial_derivatives_L2.m e Grad_Desc_L2.m — Desconvolução via Norma $L_2$.
  • cost_corr.m, partial_derivatives_corr.m e Grad_Asc_corr.m — Desconvolução via Correntropia.
1. Modelação Direta

Convolução Discreta e Modelo do Traço Sísmico

Teoria e Equações

O traço sísmico estimado $\hat{x}[i]$ resulta da convolução discreta entre a wavelet conhecida $w$ e a refletividade $r$, somada ao ruído $n$:

$$(f * g)[i] = \sum_{j=1}^{N_f} f[j]\, g[i - j + 1]$$
$$\hat{x}[i] = (w * r)[i] + n[i]$$
  • O comprimento total da convolução linear é $N_f + N_g - 1$.
  • Em prediction.m, o resultado da convolução e o vetor de ruído são convertidos em vetores-linha e truncados ao menor comprimento comum len.
convolution.m
function signal_convolution = convolution(f, g)
    % Comprimento total da convolução discreta: Nf + Ng - 1
    signal_length = length(f) + length(g) - 1;
    signal_convolution = zeros(1, signal_length);
    
    for i = 1:signal_length
        s = 0;
        for j = 1:length(f)
            index = i - j + 1; % Índice deslocado g[i - j + 1]
            if (index >= 1) && (index <= length(g))
                s = s + f(j) * g(index);
            end
        end
        signal_convolution(i) = s;
    end
end
prediction.m
function predicted = prediction(w, r, n)
    conv_res = convolution(w, r);
    
    % Garante que ambos sejam vetores-linha
    conv_res = conv_res(:)';
    n = n(:)';
    
    len = min(length(conv_res), length(n));
    predicted = conv_res(1:len) + n(1:len); % w * r + n
end
2. Abordagem Clássica — Norma L2

Função Custo $L_2$ e Derivadas Parciais

Dedução Matemática

Definindo o erro amostral $e[i] = \hat{x}[i] - x[i]$, a função custo baseada na norma $L_2$ (MSE) é dada por:

$$J_{L_2}(r, n) = \frac{1}{N}\sum_{i=1}^{N} \left(\hat{x}[i] - x[i]\right)^2 = \frac{1}{N}\sum_{i=1}^{N} e[i]^2$$

Aplicando a regra da cadeia para obter os gradientes em relação a $r$ e a $n$:

$$\frac{\partial J_{L_2}}{\partial r[k]} = \frac{2}{N}\sum_{i} e[i]\,w[i - k + 1] = \frac{2}{N}\left(e * \text{flip}(W)\right)[k]$$
$$\frac{\partial J_{L_2}}{\partial n[i]} = \frac{2}{N}\,e[i]$$

A correlação cruzada entre o erro $e$ e a wavelet $W$ é implementada no código através da convolução do erro com a wavelet invertida (conv(err, flip(W), 'full')).

cost_L2.m
function cost_value = cost_L2(trace, trace_estimated)
    N = length(trace);
    % Custo médio quadrático: (1/N) * sum((x_est - x)^2)
    cost_value = (1 / N) * sum((trace_estimated - trace).^2);
end
partial_derivatives_L2.m
function [dr, dn] = partial_derivatives_L2(W, trace, trace_estimated, r_len)
    N = length(trace);
    err = trace_estimated - trace; % Vetor de erro e[i]
    
    % Gradiente em relação a 'r' (correlação cruzada do erro com W)
    dr_full = conv(err, flip(W), 'full');
    dr = (2 / N) * dr_full(1:r_len);
    
    % Gradiente em relação ao ruído 'n'
    dn = (2 / N) * err;
end
3. Otimização — Norma L2

Algoritmo do Gradiente Descendente (Grad_Desc_L2.m)

Regra de Atualização Iterativa

Como pretendemos minimizar a energia do erro $J_{L_2}$, caminhamos no sentido oposto ao gradiente com passo de aprendizagem $\mu$ (step):

$$r^{(t+1)} = r^{(t)} - \mu \frac{\partial J_{L_2}}{\partial r}$$
$$n^{(t+1)} = n^{(t)} - \mu \frac{\partial J_{L_2}}{\partial n}$$
  • Parâmetros predefinidos: interactions = 1000 e step = 0.5.
  • A cada iteração $i$, calcula-se o traço estimado, extraem-se os gradientes [dr, dn], regista-se o histórico de custo e atualizam-se $r$ e $n$.
Grad_Desc_L2.m
function [r, n, historical_cost] = Grad_Desc_L2(W, r_init, n_init, trace, interactions, step)
    if nargin < 5 || isempty(interactions), interactions = 1000; end
    if nargin < 6 || isempty(step), step = 0.5; end
    
    rng(42);
    r = r_init(:)';
    n = n_init(:)';
    trace = trace(:)';
    W = W(:)';
    
    historical_cost = zeros(1, interactions);
    
    for i = 1:interactions
        % 1. Predição do traço atual
        trace_estimated = prediction(W, r, n);
        % 2. Cálculo das derivadas parciais
        [dr, dn] = partial_derivatives_L2(W, trace, trace_estimated, length(r));
        % 3. Registo do custo L2
        historical_cost(i) = cost_L2(trace, trace_estimated);
        
        % 4. Passo descendente (minimização)
        r = r - step * dr;
        n = n - step * dn;
    end
end
4. Critério de Informação — Correntropia

Correntropia e Derivadas Parciais

Dedução com Núcleo Gaussiano

A correntropia mede a similaridade local entre $\hat{x}$ e $x$ usando um kernel Gaussiano com largura $\sigma$ (k_size):

$$V_{\sigma}(\hat{x}, x) = \frac{1}{\sigma\sqrt{2\pi}}\frac{1}{N}\sum_{i=1}^{N}\exp\!\left(-\frac{e[i]^2}{2\sigma^2}\right)$$

Derivando em ordem a $e[i]$, surge o fator $-\frac{1}{\sigma^2}e[i]$, resultando num erro ponderado exponencialmente (que atenua outliers):

$$w_{\text{err}}[i] = \exp\!\left(-\frac{e[i]^2}{2\sigma^2}\right)\cdot e[i]$$
$$\frac{\partial V_\sigma}{\partial r} = -\frac{1}{\sigma^3\sqrt{2\pi}\,N}\left(w_{\text{err}} * \text{flip}(W)\right), \quad \frac{\partial V_\sigma}{\partial n} = -\frac{1}{\sigma^3\sqrt{2\pi}\,N}\,w_{\text{err}}$$
cost_corr.m
function cost_value = cost_corr(trace, trace_estimated, k_size)
    N = length(trace);
    err = trace_estimated - trace;
    cost_value = (1 / (k_size * sqrt(2 * pi))) * (1 / N) * ...
                 sum(exp(-(err.^2) ./ (2 * k_size^2)));
end
partial_derivatives_corr.m
function [dr, dn] = partial_derivatives_corr(W, trace, trace_estimated, k_size, r_len)
    N = length(trace);
    err = trace_estimated - trace;
    before_the_summation = -(1 / ((k_size^3) * sqrt(2 * pi))) * (1 / N);
    
    % Erro ponderado pelo kernel Gaussiano
    weighted_err = exp(-(err.^2) ./ (2 * k_size^2)) .* err;
    
    % Gradiente em relação a 'r' e 'n'
    dr_full = conv(weighted_err, flip(W), 'full');
    dr = before_the_summation * dr_full(1:r_len);
    dn = before_the_summation * weighted_err;
end
5. Otimização — Correntropia

Gradiente Ascendente (Grad_Asc_corr.m) e Comparação

Maximização da Similaridade

Ao contrário do erro quadrático, a correntropia é uma medida de similaridade (atinge o valor máximo quando $\hat{x} = x$, ou seja, $e[i] = 0$). Por isso, aplicamos o Gradiente Ascendente:

$$r^{(t+1)} = r^{(t)} + \mu \frac{\partial V_\sigma}{\partial r}$$
$$n^{(t+1)} = n^{(t)} + \mu \frac{\partial V_\sigma}{\partial n}$$
  • Norma $L_2$: Penaliza quadráticamente todos os desvios; sensível a ruído impulsivo.
  • Correntropia: Para erros elevados ($|e[i]| \gg \sigma$), o termo $\exp(-e[i]^2 / 2\sigma^2)$ tende para zero, conferindo robustez a picos espúrios e preservando a esparsidade da refletividade.
Grad_Asc_corr.m
function [r, n, historical_cost] = Grad_Asc_corr(W, trace, r_init, n_init, k_size, step, interactions)
    if nargin < 7 || isempty(interactions), interactions = 1000; end
    if nargin < 6 || isempty(step), step = 0.5; end
    
    rng(42);
    r = r_init(:)';
    n = n_init(:)';
    trace = trace(:)';
    W = W(:)';
    
    historical_cost = zeros(1, interactions);
    
    for i = 1:interactions
        trace_estimated = prediction(W, r, n);
        [dr, dn] = partial_derivatives_corr(W, trace, trace_estimated, k_size, length(r));
        historical_cost(i) = cost_corr(trace, trace_estimated, k_size);
        
        % Passo ascendente (+ step): maximiza a correntropia
        r = r + step * dr;
        n = n + step * dn;
    end
end
